```
|    🔒 Zero-Telemetry   |  |   🛡️ 3-Tier Sandbox    |  |     🏥 HIPAA & SOC2    |  |    ✈️ Air-Gap Capable   |
| No AST or code egress. |  | PTY env scrubbing &    |  | Meets strict non-      |  | Fully offline with     |

+------------------------+  +------------------------+  +------------------------+  +------------------------+
```

#### Technical Security Pillars:
1. **HIPAA & SOC2 Type II Alignment:** Because Ty-Code never routes repository files to external indexing servers, your compliance perimeter remains strictly confined to your managed hardware.
2. **Three-Tier Terminal Sandbox:** Automated agent commands run under strict allowlist policies with aggressive PTY environment scrubbing that strips API keys and secrets before execution.
3. **Hardware Credential Sealing:** All credentials remain locked in operating-system secure storage (**safeStorage**), preventing token theft from compromised local dependencies.
4. **Centralized MDM Governance:** IT security teams can deploy global policy configurations via Microsoft Intune, Jamf, or GPO to enforce private LLM VPC endpoints across 1,000+ engineers.
